## Account details

Owed stores the PayPal account name and verified email it needs for sign-in and invitation matching. It uses the accepted PayPal account as the payout destination.

## Promise details

Owed keeps role details, candidate labels, reply dates, closure messages, payment references, and status records so each person can see what happened.

## Private invitations

Invitation links are private. If the wrong PayPal account opens one, Owed doesn't reveal the intended email. An employer can replace an unclaimed invitation before its deadline, which makes the old link stop working.

## What these records show

The role and candidate pages show the saved promise. PayPal's own records show identity and money movement.
