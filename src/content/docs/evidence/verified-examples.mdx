## One candidate payment

The README records a sandbox run where a candidate accepted a promise, received no status by the deadline, and was paid $1.00 through PayPal. It proves that this tested path completed with the recorded accounts.

## A two-candidate role

The recorded example used one hold for two candidates. It includes a reminder, a still-deciding answer with a later date, and a final answer. The recorded run says both emails arrived once and the unused hold was released without a charge.

## A repeated payout request

The README records that PayPal refused a second request for the same payout, and Owed read the original payout back. This proves the tested repeat-request safeguard, not every possible recovery case.

## AI drafting on the live demo

On the live demo, AI wrote a closure letter for a sandbox candidate. When the employer added feedback about the candidate's experience, AI flagged it twice, once for giving a reason and once for comparing applicants. The employer replaced it with a plain answer, the candidate saw it, and one email arrived. This proves AI drafting and wording review worked on that run. It doesn't prove the free writing service is always available.

## What these records don't prove

These are specific sandbox results. They don't prove live PayPal readiness, universal email delivery, or real employer demand.
